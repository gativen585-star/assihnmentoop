# AUCA_ID - School Management System (OOP Practical Assignment)

## How to Compile and Run (Terminal / Command Prompt)
1. Open terminal inside the `AUCA_ID` folder.
2. Compile all Java source files into an `out` directory:
   ```bash
   javac -d out src/com/auca/interfaces/*.java src/com/auca/exceptions/*.java src/com/auca/abstracts/*.java src/com/auca/department/*.java src/com/auca/student/*.java src/com/auca/teacher/*.java src/com/auca/administrator/*.java src/com/auca/course/*.java src/com/auca/classroom/*.java src/com/auca/enrollment/*.java src/com/auca/assessment/*.java src/com/auca/feepayment/*.java src/com/auca/librarybook/*.java src/com/auca/bookloan/*.java src/com/auca/main/*.java
   ```
3. Run the application:
   ```bash
   java -cp out com.auca.main.Main
   ```
